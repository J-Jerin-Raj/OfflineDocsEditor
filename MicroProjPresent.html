System Analysis

Software Requirements Specification (SRS)

Categorization of functional specifications and quality attributes.

Functional Requirements (FR)
  • FR-01 (Rich Document Authoring): Formatting engine supporting headings, text styles, colors, alignment, lists, quotes, and code blocks.
  • FR-02 (Bi-directional Delta Sync): Broadcast operational Delta packets via Socket.IO to connected sessions without echo-loops.
  • FR-03 (Remote Cursor & Selection Awareness): Compute character coordinates using getBounds() and render carets, name tags, and selections.
  • FR-04 (Multi-Format Document Export): Export to clean PDF, Standalone HTML, Markdown (.md), Plain Text (.txt), and Raw JSON backup.
  • FR-05 (Dual-Layer Persistence): Simultaneous synchronous LocalStorage cache and debounced Node.js file system serialization.
Non-Functional Requirements (NFR)
  • NFR-01 (Resource Constraints): Browser memory consumption must remain strictly under 25MB during sustained multi-page typing.
  • NFR-02 (Latency & Sync Speed): Keystroke-to-socket transmission under 10ms on local network; zero UI thread blocking.
  • NFR-03 (Fault Tolerance & Offline Continuity): Server disconnects must never interrupt document authoring; sync auto-recovers upon reconnect.
  • NFR-04 (Zero External CDN Dependency): All runtime scripts, stylesheets, and fonts must be locally vendored for air-gapped environments.
  • NFR-05 (Cross-Device Uniformity): Document canvas dimensions strictly locked to 816px across desktop and mobile devices.

UX & Media Engineering

Mobile Uniformity & Print Engine

Overcoming viewport constraints and guaranteeing print fidelity.

Mobile Viewport & Horizontal Pan

Standard mobile responsive designs shrink paper to 100% phone width, causing lines to wrap 3–4 words prematurely and corrupting document structure.

  • Fixed 816px A4 Canvas: Preserves exact character line wrapping on phone and laptop.
  • Smooth Touch Panning: Enabled `-webkit-overflow-scrolling: touch` with `overflow-x: auto`.
  • Font Inflation Suppression: Enforced `-webkit-text-size-adjust: 100% !important` to prevent iOS WebKit from artificially inflating font size.
  • Sticky Screen Header: Navigation, Print button, and More menu stay locked at 100% screen width while paper pans underneath.
The `@media print` Engine

Replaces fragile DOM swapping methods (which previously wiped event listeners) with a clean CSS-driven print pipeline.

  • Total UI Suppression: Hides headers, toolbars, presence avatars, cursors, and toast overlays.
  • Smart Page Break Protection: `page-break-after: avoid` prevents orphan headers at page bottoms; `break-inside: avoid` protects paragraphs and code blocks.
  • Exact Color Reproduction: Configured `-webkit-print-color-adjust: exact`.
  • Dynamic Title PDF Naming: Browser print engine automatically names the exported PDF to match the document title.

Scalability, Future Scope & Conclusion

Extending architectural capabilities and academic summary.

Scalability & Architectural Roadmap
  • 1. CRDT Integration (Yjs / Automerge): Upgrade operational delta broadcasts to conflict-free replicated data types for decentralized peer-to-peer mesh synchronization without central server authority.
  • 2. Multi-Node Clustering (Redis Pub/Sub): Implement Socket.IO Redis Adapter to horizontally scale across multiple Node.js instances supporting thousands of concurrent rooms.
  • 3. End-to-End Encryption (E2EE): Client-side Web Crypto API (AES-GCM-256) to encrypt deltas in transit and at rest on the file system.
  • 4. Git-Style Version Branching: Snapshot commits and visual difference comparison (diffing) for document revision history.
  • 5. Native Binary Packaging: Wrap with Electron or Tauri to distribute as a zero-overhead native desktop application.
